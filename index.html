Overview

A Probability & Statistics project: predict final CGPA from five academic and lifestyle numbers, and compare a linear model with a random forest.

I fitted two models on the same 4,000 / 1,000 split (test_size=0.2, random_state=42). The predictors are study hours per day, attendance, sleep, social hours in the week, and previous CGPA. The linear model is ordinary least squares:

Final_CGPA = b0 + b1*Study_Hours_Per_Day + b2*Attendance_Pct + b3*Sleep_Hours + b4*Social_Hours_Week + b5*Previous_CGPA

The linear fit is a sklearn.linear_model.LinearRegression (intercept on, no scaling). The second model is a sklearn.ensemble.RandomForestRegressor with 100 trees and random_state=42. Gender, age and major are in the table and I summarised them, but they are not inputs to either model.

I re-ran the work from src/predict_cgpa.py. Linear regression matched the original notebook exactly: test MSE 0.02601314, R² 0.90928834. The forest is ahead — MSE 0.01632421, R² 0.94307506 — close to the notebook’s 0.01634155 and 0.94301461. Previous CGPA does most of the work. The numbers from that run are under results/.

How the Models Are Fitted

The work is in src/predict_cgpa.py and in the notebook. The steps are the same in both.

1

Load the table

Read data/Student_data.csv. If the file is missing, the script stops and points at data/README.md.

2

Look at the data

Print the summary statistics, the Pearson correlations, and the Tukey IQR outlier counts. Outliers stay in the table.

3

Fit both models

Split 4,000 / 1,000 with random_state=42. Fit LinearRegression() and a 100-tree RandomForestRegressor on the same five predictors.

4

Write the report

Print the equation and write results/metrics.csv, results/coefficients.csv and results/predictions_head.csv.

Neither model standardises the inputs. I did not drop outliers, add interactions, or tune the forest. The point of the exercise is this comparison, on the same split the original notebook used.

Test Results

Test set, 1,000 rows. Linear regression matches the original notebook exactly. The forest figures are from my re-run; the notebook had MSE 0.01634155 and R² 0.94301461, which is the same conclusion.

The forest is ahead on every test metric. On the training set, linear regression is consistent (train R² 0.9022, test 0.9093), while the forest is nearly perfect on the training rows (R² 0.9906) and drops to 0.9431 on the test set. It is over-fitting a bit, but it still wins on held-out data.

Previous CGPA does most of the work in both models. Sleep and social hours are tiny; given how close their correlations are to zero, I would not treat those signs as a finding. The leftover residuals of the linear model are a fairly tight band around zero — a test RMSE of 0.16 on a CGPA scale of about three points is small, and I do not see a strong curve that would say a straight line is the wrong shape entirely.

Learned equation

Final_CGPA = -0.678843 + 0.045074×Study_Hours_Per_Day + 0.010971×Attendance_Pct - 0.000971×Sleep_Hours - 0.003800×Social_Hours_Week + 0.926166×Previous_CGPA

How to run

Python 3, with the packages in requirements.txt. The CSV is already in data/.

Linux / macOS

git clone https://github.com/rohaan2802/CGPA_Prediction.git
cd CGPA_Prediction
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 src/predict_cgpa.py

Windows

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python src\predict_cgpa.py

That prints the summary statistics, the correlations, the coefficients, the test metrics and the linear equation, and writes files under results/. Optional flags: --data-dir, --results-dir and --no-plots. The same steps are in notebooks/cgpa_prediction.ipynb.
